# Finance · 海外项目与出口财务

HayesKung/Finance 是 MM-FINPIVOT 的跟踪仓库：业务机制、架构、文案、模板、可运行界面源码与验收任务。

- 方案正本：Google Drive 文件 ID 1W1HoXgeM4CMTGLZvsXnfwjKhf8vb3nDC。
- 价格、话术和业务红线以已确认的 Drive 方案为准。
- 品牌名、域名、联系方式和对外发布尚需本人确认；仓库中的页面仍按草案和内部工作台管理。
- 已部署或能启动不等于已通过生产安全 Gate，也不等于获准对外承接真实客户资料。

## 当前实现边界

- 已有线索、诊断、名单、约访、获客、模板、作战台、订单与服务确认书相关模块。
- 作战台主数据仍主要保存在操作者的浏览器本地；合同/签署相关数据另通过服务端 API 使用 PostgreSQL。当前不能把它描述为已完成统一客户/项目数据库。
- docs/03-本地构建.md 明确当前 AuthProvider 是透传，不是真实身份认证或服务端授权。
- 在真实认证、服务端授权、客户数据隔离、恢复演练和最终 Gate 通过前，不开放公网或导入真实客户敏感资料。

## 本地开发

执行 npm install 后运行 npm run dev。开发服务默认绑定 127.0.0.1。生产启动另有 listen.mjs 的回环地址核验；不要绕过该入口，也不要在鉴权未完成前扩大监听范围。

页眉支持中文 / EN。台账的阶段、产品和收款词仍按中文保存，英文仅为显示。服务费保持人民币；项目合同额按填写的记账汇率换算结算币，不是预测，也不代替银行牌价。
