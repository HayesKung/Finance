# Finance · 海外项目与出口财务

HayesKung/Finance 是 MM-FINPIVOT 的跟踪仓库：机制、文案、模板、可运行界面的业务源码。

- 方案正本在 Google Drive，文件 id `1W1HoXgeM4CMTGLZvsXnfwjKhf8vb3nDC`。
- 价格、话术、红线不在本仓库里改口。
- 品牌名和联系方式未确认，仓库里的页面是草案和内部作战台，不是已授权的对外发布。

从这里看：

- `docs/00-机制总纲.md`：角色、阶段、红线、检查点。
- `docs/01-官网七区块.md`：对外页面顺序。
- `docs/03-本地构建.md`：缺的构建文件、版本锁定、只监听本机。鉴权还没做，不要放到公网。
- `docs/04-对外与内部.md`：对外页只做介绍和收需求；名单、客户、订单在内部工作台。
- `src/`：对外页、需求单、诊断、名单、约访、获客、模板、作战台。数据只在浏览器本地。
- 页眉可以切中文 / EN。台账里的阶段、产品和收款词仍按中文保存，英文只是显示。服务费保持人民币。项目合同额按填写的记账汇率换成结算币，不是预测，也不代替银行牌价。

本机：`npm install`，然后 `npm run dev`。服务只绑 127.0.0.1。
