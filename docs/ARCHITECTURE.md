# ARCHITECTURE

状态：IN_PROGRESS。这是 `work/e2e-001` 的结构说明，不是生产验收。

浏览器上的对外页（`/`、`/ask`、`/sign`）不要求工作人员登录。内部页要先有服务器签发的 `fin_staff` cookie。Cookie 由 `FINANCE_SESSION_SECRET` 签名，12 小时过期，HttpOnly。

两个角色：

- `owner`：财务负责人。可以保存支付密钥、撤销确认链接、保存台账。
- `support`：支撑人员。可以发确认书和看台账，不能保存支付密钥，不能撤销链接。

口令只放在服务器环境变量里。程序不保存口令，也不接受由浏览器自己声明角色。

Postgres 是确认书、审计、限流和已保存台账的正式存储。未点保存或服务器还没有版本时，浏览器里的旧台账仍只在本机。保存时服务器按上一版重新检查开工、实收和复核，不信任浏览器传来的“已通过”。

支付密钥写入前用 AES-256-GCM 加密。接口只返回“是否已配置”，不把密钥发回浏览器。微信、支付宝、持牌电子签都还没有正式下单或签署调用。

未做：生产主机本轮没有重新部署。公网是否仍能转到回环端口，本轮没有复测。
