# SECURITY_AND_PRIVACY

已在代码里做到的：

- 内部页面没有会话时不渲染台账。
- 支付密钥接口不再接受匿名调用，保存值不是明文。
- 确认链接有期限和撤销，失败次数按来源地址限流。
- 审计记的是哈希，不是 token 原文。
- `robots.txt` 只是提示，不是访问控制。

还没有做到、因此不能称为生产安全：

- 本轮没有从外部复测生产端口和反向代理。
- 客户联系方式在 `fin_desk.body` 里仍是明文。
- 没有备份恢复演练。
- 没有文件上传和销毁流程。
- 会话固定 12 小时，没有设备清单。
- 限流在不信任 `X-Forwarded-For` 时，可能把代理后的所有人算成同一个地址。只有确认代理可信才设置 `FINANCE_TRUST_PROXY=1`。

口令、`DATABASE_URL`、`FINANCE_SESSION_SECRET` 和 `FINANCE_DATA_KEY` 只放在服务器的 env 文件。不要写入仓库、任务卡或聊天。
