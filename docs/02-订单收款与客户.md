# 订单、收款、客户与项目

这是服务流程，不是支付通道。

## 端到端

1. 名单里只记公开线索。
2. 升为客户，或直接建客户档。客户下面挂他的出口票或海外项目。
3. 诊断只出风险清单，不在这一步开工。
4. 建草稿订单：客户、可选项目、产品、收费方式、财务人员确认后的金额。系统不自动报价。
5. 生成收款计划。
   - 按单：定金 50%，尾款 50%。
   - 月度：当月费用 100% 预收。
   - 阶段：首段 50%，其余交付前结清。
6. 定金、当月预收或首段费用记到“已收”之后，才允许改成执行中。
7. 交付物按产品勾完，并且每一笔都收齐，才允许改成已交付。
8. 已交付不能直接取消。草稿不能直接标已交付。
9. 复盘和案例公开仍要客户同意，不在订单状态里自动公开。

金额为 0 的订单不能生成收款计划。不接受先做后看。

## 不做什么

- 不发起扣款，不接支付网关。
- 不登记、不代收客户自己的项目回款、退税款或贷款。
- 这里的“已收”只表示服务费是否进了服务方自己的账户，由财务人员本人登记。

规则在 `src/lib/finpivot/flow.ts`，页面不能绕过。
